# AFUED SDE Directorate website

A responsive frontend demonstration for the Skill Development & Entrepreneurship Directorate at Adeyemi Federal University of Education.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run build` to create a production build and `npm run lint` to check the source.

## Content status

The university address, general contact details, crest, name and founding year come from AFUED materials. Programme titles are normalized from the published AFUED 2024/2025 final SDE selection spreadsheet. Current availability, director profile, most staff roles, schedules, detailed programme descriptions, equipment lists, directorate mission/vision and messages remain provisional until the directorate supplies official content.

The latest published SDE directorship (Dr. E. O. Fehintola) covered 1 August 2025 to 31 July 2026. No successor was found at the time of this update, so the interface deliberately does not claim a current director. AFUED reported Mrs. Folashade Olujoke Izuagie's appointment as Deputy Director in February 2026.

The contact form validates information in the browser for demonstration purposes. It does not send or store submissions.
